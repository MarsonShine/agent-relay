## RC1：租约测试稳定性

[原 CI 首次尝试](https://github.com/MarsonShine/agent-relay/actions/runs/39577921172/attempts/1) 在 Windows 以 197 通过、1 失败结束；Linux 通过。失败栈位于 `test/workspace-access.test.ts` 的定时续租回调，经 `Runs.renew` 进入 `Runs.owned`，报租约已过期。[第二次尝试](https://github.com/MarsonShine/agent-relay/actions/runs/39577921172/attempts/2) 两平台通过。

证据表明失败发生在测试的续租调度，而不是“后端收到旧快照”的目标断言。原用例将租约设为 1000 ms，每 200 ms 续租并等待 1100 ms，同时执行真实 Git/文件检查；它隐含依赖回调在租约窗口内获得调度。导致该次调度延迟的具体系统负载未测量。

受保护的不变量：工作区准备完成后，首次启动与续接必须携带数据库中仍有效的当前 Run；真正过期或停止未知时不得启动另一个执行者。生产层 `WorkspaceExecutor.launch` 已刷新 Run，`WorkspaceAccess` 和 `Runs` 已拒绝过期所有权，因此本次修复归属测试层。

测试仅控制 `Date`，保留真实 Git I/O 与进程超时。在准备过程中显式推进 800 ms、续租、再推进 300 ms，使原快照必然过期而当前租约有效。首次启动和续接分别断言当前到期时间、owner、证据及结算前后的占用；另分别验证准备期间真正过期时后端不启动、Run 保持隔离，确认停止后才能结算。未放宽生产租约，也未加入重试。

负向校验已暂时移除交接处的 Run 刷新，两条续租用例均在租约有效性断言处失败，随后原生产文件已恢复。这样验证用例能发现原本要防止的回归。真实 heartbeat、取消和崩溃恢复仍由现有完整测试覆盖；可控时间用例不声称验证操作系统调度性能。

本机 Windows 完整 `npm run check` 已通过：类型检查、格式、构建及 201 项测试，0 失败、0 跳过。首次受限环境运行因拒绝停止测试子进程而出现环境性失败，已终止且不计为通过；确认相关进程不存在后，在允许停止测试子进程的环境中运行相同门禁并通过。这是推送前的本地验证快照；远端验证须绑定 PR 的精确提交，结果记录于 PR 检查与本文件的交付记录。

## RC3：真实业务试点

状态：维护者明确暂缓，留待后续确定真实仓库或 issue、实际需求、可执行验收、调用预算及试点权限。本轮提交/推送授权仅适用于收尾改动。既有 M3/M4 记录不能替代新增试点。

启动前冻结以下信息，私有内容保存在独立运行目录：

- 控制器提交和构建、目标仓库基线、需求版本、允许文件、已有仓库规则及独立验收条目。
- 可信检查的定义版本、绝对可执行路径与参数；只使用现有规则允许的操作。
- 默认 `gpt-6-luna`，明确最大调用数、单次时限、总期限和修复轮次；增加预算必须单独授权并保留原计数。
- 单独的控制目录、工作树根和目标 checkout；不复用原 unknown 实例。明确本地提交、远端推送/PR 的授权范围。

首次试点以一个有明确需求的小范围业务任务为单位。先执行可信检查基线，再创建任务；完成后核对候选、独立审查覆盖、未解决发现、全部停止及占用为零，重新打开服务再次核验 accepted。若授权 GitHub 交付，再核对当前 SHA 的 CI 和 delivered。

| 指标 | 统计口径 |
| --- | --- |
| 业务成功 | accepted 且重开后证据有效的任务数 / 已启动任务数；失败、blocked、unknown 均保留在分母 |
| 交付成功 | 仅对事前授权交付的任务统计 delivered 数 / 该类已启动任务数；本地试点记不适用 |
| 人工介入 | 每次问题答复、需求修订、权限处理、预算追加、恢复或候选确认分别记时间和原因；初始配置单列 |
| 调用消耗 | 保存 runsUsed、iterationsUsed、infrastructureRetriesUsed；按 runId 去重统计 usage 事件的输入/输出 token，缺失条目单列未知 |
| 时间与成本 | 记录端到端耗时及等待人工时间；供应商未提供费用则记未知，不从调用数估算金额 |
| 质量 | 独立审查有效发现、人工发现的漏检、修复轮次、范围外变更和后续返工 |

试点结果只报告原始计数（例如 1/1）和具体限制，不推导普遍成功率。遇到未知停止、越权需求、预算/期限耗尽或证据不完整即停止推进，保留实例与失败记录。是否进入 A1 在试点结果与人工复核后另行决定。
