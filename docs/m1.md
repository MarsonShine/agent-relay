# M1 控制内核契约

M1 只运行无模型费用、只读的 simulation 任务。实体和执行输入/输出均带 `schemaVersion: 1`；数据库迁移版本与协议版本分别管理。M0 尚未验证的真实写入能力保持禁用。

配置使用严格 schema。角色 design / implement / review 与执行器、供应商、模型、权限分别记录，配置在创建任务时冻结，运行再次保存快照。当前唯一允许的组合为 fake / simulation / simulator-v1 / read-only；原生参数由 fake 适配器定义。未知字段、未知模型、未支持权限和无限预算均拒绝。

需求版本和代码版本绑定每个 Run、Artifact、Finding。代码版本可以为空，表示没有代码验证证据；不得把空版本解释为任意提交。resolved 发现必须有复验说明。金额和 token 用量不可见时记为未知。

执行接口由 start、continue、cancel、reconcile 和事件流/结果组成。续接引用是不透明字符串；工作流不能解析原生会话 ID。能力不支持时显式失败，不自动换模型或放宽权限。M1 定义 Finding 的持久格式，审查与发现处理工作流在 M2 实现。
