# M1 控制内核契约

M1 只运行无模型费用、只读的 simulation 任务。实体和执行输入/输出均带 `schemaVersion: 1`；数据库迁移版本与协议版本分别管理。M0 尚未验证的真实写入能力保持禁用。

配置使用严格 schema。角色 design / implement / review 与执行器、供应商、模型、权限分别记录，配置在创建任务时冻结，运行再次保存快照。当前唯一允许的组合为 fake / simulation / simulator-v1 / read-only；原生参数由 fake 适配器定义。未知字段、未知模型、未支持权限和无限预算均拒绝。

需求版本和代码版本绑定每个 Run、Artifact、Finding。代码版本可以为空，表示没有代码验证证据；不得把空版本解释为任意提交。resolved 发现必须有复验说明。金额和 token 用量不可见时记为未知。

执行接口由 start、continue、cancel、reconcile 和事件流/结果组成。续接引用是不透明字符串；工作流不能解析原生会话 ID。能力不支持时显式失败，不自动换模型或放宽权限。M1 定义 Finding 的持久格式，审查与发现处理工作流在 M2 实现。

SQLite 在启动时以事务执行有序 migration，拒绝较新数据库版本，并执行 quick_check。创建任务的 requestKey 绑定规范化后的完整请求；同键同内容返回原任务，同键不同内容报冲突。任务命令带 expectedVersion；旧版本、终态修改、未确认停止时 resume 均拒绝。状态、事件和 Decision 同事务保存。事件序号全局单调，按任务分页读取；相同事件键内容不一致报冲突。

answer 必须匹配 waiting_user 的问题 ID/版本，保存 Decision 并增加 requirementVersion；旧成果仍可查看但不能作为新需求的完成证据。暂停保留 deadline 和已消耗预算；暂停待答复任务后恢复仍回到 waiting_user。

运行领取、消耗次数、配置快照、租约及领取事件在同一事务持久化。数据库部分唯一索引限制全局最多一个 active/unknown Run，符合 v1 默认串行执行。租约由随机 owner 标识约束；过期续租及旧 owner 结果拒绝。过期只进入 recovering，不回收占位。执行器明确确认停止后才释放；未知状态不会启动第二个运行。

pause/cancel 活动运行时先持久化控制意图并进入 recovering。停止确认之前不能 resume；完成与取消竞态按事务顺序决定，已保存的 cancel 优先于迟到成功。M1 重启后无法核对的模拟进程保留 recovering；生产进程身份与副作用恢复由 M3 完善，不根据 PID 或到期时间猜测停止。

成果以 SHA-256 内容地址存储。先写独占临时文件并 fsync，再用硬链接原子发布；数据库引用失败可能留下无引用文件，不静默覆盖既有成果。每次读取校验类型、大小和哈希。每个 Run 的 result/log 各一份；不同内容的重复写入报冲突。日志与成果在发布前按 UTF-8 字节限额检查，脱敏后再次检查。

脱敏覆盖显式传入的密钥、常见 credential 字段、Bearer、URL 凭据及常见本机路径；它不是完整 DLP。任务输入、决策和数据库仍是私有数据，整个数据目录不得上传。运行目录默认仅本机用户使用；Unix 创建为 0700/0600，Windows 依赖用户目录 ACL。缺失/损坏成果通过诊断显式报告，原始内容不返回。

模拟适配器通过 shell:false 启动已知的单个 Node 子进程，覆盖成功、失败、无终态、重复事件、待答复及静默超时场景。原生协议解析、输出上限和进程退出归适配器；工作流只接收通用事件/结果。没有终态的零退出返回 unknown。模拟器不支持原生续接，答复后由控制器显式创建新 Run。新适配器实例不能凭旧记录猜测进程停止。

控制器通过注入 Executor 替换执行后端，不读取原生事件或会话格式。运行期间续租，运行时限与任务绝对 deadline 取较小者。超时、取消或解析/落盘失败均要求确认停止；未知结果保留租约。模拟任务成功要求已停止、通用 completed 事件、非空成果、匹配的需求版本/代码版本及成果落盘后哈希复读。该 succeeded 仅代表模拟内核验收，不代表真实需求实施或代码验证。

待答复状态不再调度；答复后以新需求版本创建新 Run。控制器关闭时持久化 pause 并停止活动运行。重启保留次数和绝对期限，不自动重放未知运行。预算包括等待及暂停的墙钟时间；M1 无自动修复或重试循环，maxIterations 为后续工作流的有限配置契约。

本地通道采用 127.0.0.1 HTTP，默认端口 4318。每个数据目录首次记录监听端口，此后重启复用；端口绑定和首次登记独占写保证同一目录不出现两个服务。未关闭的旧服务导致 EADDRINUSE，不能通过换端口绕过。令牌为随机 256 bit，保存在私有目录，不出现在参数或日志中；CLI 每次从该目录读取。

所有 `/v1/` 请求包括 health 都要求 Bearer，校验精确 Host 并拒绝带 Origin 的浏览器请求。无 CORS，非公网绑定，无远程访问承诺；同一 OS 账户及管理员仍属于本机信任边界。请求体限制 128 KiB，读请求与变更都使用版本化结构；未知字段拒绝。create 仅接受目录和任务文本，策略来自服务配置并冻结。status 返回 evidenceIssues 和 accepted，已完成后成果损坏也不会继续显示 accepted=true。
