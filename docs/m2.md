## M2.1 首个切片：原生事件解析

`src/adapters/codex/events.ts` 将单次 Codex CLI 的 JSONL 转为通用 started/progress/usage 事件及轮次结果。原生命令和会话格式保持在适配器内；续接引用是不透明的适配器数据。当前解析器仅接受 M0 已验证的 CLI 版本 0.162.0-alpha.17.2，其他版本显式拒绝，后续版本需要独立复验。

解析按 UTF-8 字节分块，分别限制总输出、单行长度与事件数。重复事件去重；相同标识的不同内容、冲突会话、非法顺序、无终态、截断或无效 UTF-8 均不能成为成功依据。未知信息事件可忽略，但不能推动完成。

`turn_completed` 只表示 CLI 协议完成，解析器不会发出任务 completed 事件。后续适配器必须联合进程退出、结构化成果、权限和需求/代码版本证据决定 ExecutionResult；模型自述完成不能替代这些条件。非零退出或失败终态不会被后续完成消息覆盖。

验收使用 M0 的公开协议投影及合成用例，覆盖分块中文、重复/未知事件、终态冲突、异常退出和所有大小限制。投影中的会话占位符在测试中替换为固定合成 UUID，不包含实际会话或原始日志。这一切片不调用模型。
