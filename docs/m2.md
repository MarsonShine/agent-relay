# M2：本地研发闭环

## 原生事件与执行契约

`src/adapters/codex/events.ts` 将单次 CLI 的分块 UTF-8 JSONL 转为通用 started/progress/usage 事件及轮次结果。当前仅接受 M0 已验证的 0.162.0-alpha.17.2；其他版本显式拒绝。分别限制总输出、行长和事件数；重复事件去重，冲突、截断、无终态与非法序列不能证明成功。未知信息事件不能推动完成。

`CodexExecutor` 实现 start/continue/cancel/reconcile。doctor 通过同一启动命令验证实际 CLI 版本；任务正文通过 stdin 传入，原生命令使用参数数组与 shell:false。启动程序及可选 bootstrap 参数只能来自可信控制配置。完整输出 schema 同时传给 CLI 和模型提示，避免模型自行猜测结果格式。

CLI 轮次结束不等于任务完成。只有进程退出、完整成功终态、严格结果 schema、非空结果及匹配的需求/代码版本同时成立，才发出角色 completed。blocked 映射为未接受结果；非零退出、错误终态、缺失/超大/无效成果、旧证据都不能被模型总结覆盖。角色 completed 仍需后续工作流验证才能成为任务 succeeded。

角色配置支持 codex-cli / openai / gpt-6-luna，原生参数仅接受已验证的 low。design/review 必须只读；Run 配置必须等于任务冻结的对应角色配置，不能在交接时扩大权限。实施会话使用 GPT-6 Astra，应用内部真实测试调用使用 GPT-6 Luna。

## 工作区与权限

Codex 请求必须带控制层声明的工作区。写入只允许指向原 checkout 之外的隔离 worktree，且有基线提交；适配器拒绝原路径、其子路径及缺少声明的写入请求。M2.2 将负责创建、登记和核对真实 worktree，模型或任务文本不能自行指定该声明。

Windows 显式保留原生 elevated 沙箱。只读角色禁用 sandbox_approval、request_permissions 等能力扩展审批，保留执行规则审查及所有项目规则。环境保留继承的 Codex 策略与本机认证上下文，但不转交 GitHub、其他供应商密钥或 NODE_OPTIONS。MCP/hooks 与生产控制目录的完整隔离仍需在工作区接入阶段审计；目前服务继续只注册模拟执行器。

成果目录位于 Agent 工作区之外，每个 Run 独占新目录。最终输出必须是大小受限的普通文件，符号链接和重复目录拒绝。stderr 有界收集并在保存前脱敏；原始输出和本机续接资源仅留在私有运行目录，不进入公开 fixtures。

## 续接与生命周期

不透明续接引用绑定任务、完整角色配置和规范化工作区。新 Run 可以显式续接同一资源；角色、模型、权限或工作区变化必须新建会话。拒绝 --last；实际返回另一个会话时拒绝结果并清空该引用。

启动前取消会锁住启动意图，异步预检完成后也不会再创建进程。运行时限取角色时限与任务剩余期限的较小者；stdout/stderr 合计限额，超限也触发停止。Windows 强制终止拥有的活动 PID 树，Linux 终止进程组；只有终止确认和输出管道关闭后才报告 stopped。父进程已经退出但管道仍被占用时不猜测 PID，返回停止未知。此时控制器必须保留租约。

新适配器实例没有旧进程的可靠身份，reconcile 返回 unknown，绝不根据裸 PID 或过期时间启动第二位写入者。M3 负责跨服务重启的身份和副作用核对。本阶段未承诺软中断或后台/脱离进程恢复；测试工具必须保持前台。

## M2.2 登记与 Git 生命周期（M2-workspaces-v1）

SQLite migration 4 记录原仓库及 common-dir 身份、基线提交、任务分支、规范化路径、需求版本和工作区状态。先持久化 creating 意图，再执行 Git；Git 已成功而数据库未确认时保留未完成意图，拒绝自动重放。inspect 只核对现状，不把未知创建或删除操作自动重试，恢复调度留给 M3。

实现工作区在原 checkout 外创建 codex/task-<task-id> 分支，以记录的 SHA 为基线；原 checkout 的未提交源码不复制、不修改。审查使用独立 detached HEAD worktree，记录明确的需求版本和提交，并保存有界内容摘要。Git worktree lock 仅用于防止清理/移动，不是文件写锁。

仓库规则必须能从该提交复现；本地未提交/忽略的 AGENTS、.agents、.codex 配置导致预检失败。自定义 checkout hooks、checkout filters、fsmonitor、symlink/submodule 树以及隐藏或稀疏 index 暂不接入，直接拒绝，不通过忽略规则或执行隐含脚本绕过。内容摘要拒绝链接/特殊文件，限制 100000 项、单文件 32 MiB、合计 256 MiB，超限显式失败。

咨询使用干净且匹配记录 SHA 的原仓库只读声明，不创建分支或 linked worktree。清理只允许终态任务、无占用且干净的登记 worktree；忽略文件也会阻止清理，不使用 force/reset，不删除分支，保留已提交历史。当前已完成登记/Git 生命周期；Run 占用和执行器保护在同一 M2.2 后续提交接入。
