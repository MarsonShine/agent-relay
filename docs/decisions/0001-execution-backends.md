# ADR 0001：以执行后端隔离跨 Agent 编排

日期：2026-10-15
状态：已接受

## 背景

产品需要把多轮调查、设计、实现、审查与交付自动化。近期需要复用现有 coding harness 快速落地；长期需要允许直接调用官方模型 API，自主管理 Agent 工具循环。

## 决策

1. TypeScript，本地服务 + CLI；后续 Web UI。
2. v1 通过子进程调用 Codex CLI，不以直接模型 API 或 Codex SDK 作为必需执行路径。
3. 定义任务级 Agent 执行接口，隔离 Codex 原生事件、参数和续接会话。
4. 角色与执行器、模型供应商、模型、思考参数和权限分别配置。
5. API Agent 是后续执行后端，其供应商适配位于后端内部；只使用官方 API。
6. 任务事实存于控制层；跨后端交接使用版本化成果与证据。
7. 第一版交付至 PR，自动合并作为后续独立能力，默认关闭。
8. 公开源码仓库命名为 agent-relay，目标所有者 MarsonShine；许可证单独决定。

## 后果

首版工程量集中在状态、交接、验证、恢复和 CLI 兼容。执行接口通过模拟后端检验，而不是为了未来供应商建立大量占位抽象。

后续 API 路线需要工具循环、上下文、沙箱和验证工作；不会把一次 HTTP 调用视为完整 Agent。后端能力差异通过声明和预检暴露，不能静默降级权限或模型参数。
